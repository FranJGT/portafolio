# Portafolio personal

Sitio web personal donde reúno mis proyectos de desarrollo web, ciencia de datos y tecnología educativa.

## Tecnologías

HTML, CSS y JavaScript (sitio estático).

## Cómo verlo

Abre `index.html` en tu navegador, o sírvelo localmente:

```bash
python3 -m http.server 8000
# luego abre http://localhost:8000
```

## Estructura

- `index.html` — página principal
- `sections/` — secciones del sitio
- `images/` — recursos gráficos
